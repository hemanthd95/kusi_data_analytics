Extra Insights from Class Demo (Optional but Helpful)
Planning first = faster execution
●
Spend more time in planning mode than you think.
●
Read assumptions before approving execution.
●
A strong plan lets the agent run longer with fewer interruptions.
AI workflow habits that reduce mistakes
●
Run one write session at a time per branch.
●
Let the agent self-correct minor errors before interrupting.
●
Ask for complete provenance (scripts + outputs), not outputs alone.
Git/branch habits used in demo
●
Never do assignment work directly on main.
●
Use feature branches per assignment and push frequently.
●
Keep commit messages descriptive so review history is clear.
VS Code / Codespaces operating tips
●
Codespaces is safer when you are learning: easy reset, less local risk.
●
Use side-by-side panel layout to view code and rendered markdown together.
●
Keep one focused terminal/session for the active assignment run.
Data realism and scope control
●
Prefer real field/API data over synthetic placeholders.
●
Start with a small sample to verify pipeline, then scale up.
●
Keep Assignment 3 in EDA scope: clear summaries, visuals, and data-quality notes.
Model usage note
●
Free models can complete this work; they may just need more iterations.
●
Good prompts and planning quality matter more than model price for these assignments.
If you are unsure whether something is required, follow this sheet first.
