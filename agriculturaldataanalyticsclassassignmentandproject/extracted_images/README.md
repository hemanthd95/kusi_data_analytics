# Generated page images

Generated JPEG page images are not committed because this repository's GitHub
branch-update workflow does not support binary diffs.

Create them locally with:

```bash
./agriculturaldataanalyticsclassassignmentandproject/extract_all.sh
```

The images will be written to the ignored directory
`agriculturaldataanalyticsclassassignmentandproject/.generated/extracted_images/`.
The extraction source and all machine-readable text outputs remain tracked.
