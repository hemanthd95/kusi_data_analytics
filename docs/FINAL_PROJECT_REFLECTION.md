# Final Project reflection

My biggest “aha!” moment was realizing that a useful agricultural dashboard is not simply a collection of attractive graphs. The same dataset becomes much more valuable when the interface starts with a management question—such as which field to scout first—and then shows the evidence, uncertainty, and next verification step.

The project also reinforced that missing information is part of the analysis. The repository has strong field, crop-history, soil, climate, and limited satellite evidence, but it does not contain yield, current soil moisture, current weather, or laboratory soil-health measurements. Refusing to fabricate those values made the dashboard more scientifically credible and led to a better decision-support design: rank field follow-up, explain the ranking, and require measurement before action.
