# AI usage summary

AI assistance was used as a technical collaborator throughout the agricultural analytics course. It helped translate assignment briefs into reproducible checklists, structure Python modules, troubleshoot geospatial and notebook failures, design independent verifiers, and improve documentation.

For the Final Project, AI helped organize six assignments into a coherent decision workflow, propose transparent field-priority formulas, and draft dynamic advisory rules for non-technical users. Every rule was constrained to verified repository variables. AI was also used to identify unsupported claims: the final dashboard does not invent the assignment's example 200-field package, predicted bushels, current soil moisture, current weather, laboratory soil-health measurements, or field-specific NDVI beyond the one authentic Landsat field.

The most important use of AI was iterative verification. Several earlier assignments exposed issues that superficially green CI checks could miss, including generated files not committed to the branch and a nested NDVI key mismatch. Those lessons shaped the Final Project's independent recomputation, output-inventory checks, deterministic build tests, and explicit provenance summary.

AI-generated recommendations in the dashboard are deterministic, evidence-linked captions rather than free-form agronomic prescriptions. They prioritize follow-up and always tell the user to confirm current crop, soil, weather, pest, and field conditions before acting.
