# Assignment 6 — Weather and Climate Trends

**Status: complete.** This assignment analyzes authentic NASA POWER daily weather data for the 25 authoritative South Carolina fields. No mock, random, substituted, or synthetic observations are used.

## Analysis scope

The source is the official NASA POWER Daily Point API, Agroclimatology community, using LST for 1991-01-01 through 2025-12-31. The six variables are T2M, T2M_MAX, T2M_MIN, PRECTOTCORR, RH2M, and ALLSKY_SFC_SW_DWN. A CSBACRES-weighted centroid of projected field centroids defines one deterministic request point at 34.33090814° N, 82.53604245° W.

The workflow validates the authentic response, preserves the raw bytes and checksum, creates a complete daily index of 12,784 records, calculates monthly and annual summaries, April–October warm-season metrics, 1991–2020 climate normals, 2021–2025 anomalies, and OLS, Theil–Sen, and Kendall trend statistics.

NASA POWER is a gridded product rather than an on-site station. One grid point represents the overall field cluster and does not resolve field-to-field meteorological differences. Weather thresholds are descriptive and do not independently establish crop injury or causation.

## Repository contents

- `source/`: authentic raw response, request and response metadata, checksummed source manifest, representative point, and field-distance evidence.
- `output/tables/`: daily, monthly, annual, warm-season, normals, anomaly, trend, and quality-control tables.
- `output/visualizations/`: six committed SVG analytical figures. Equivalent PNG figures are reproducible build products and may also be committed because the Assignment 6 PNG paths are explicitly permitted by `.gitignore`.
- `output/dashboard_assets/`: two reproducible PNG dashboard assets generated by the analysis script; these paths are also explicitly permitted by `.gitignore`.
- `scripts/`: acquisition, analysis, and notebook-building workflows.
- `verify_assignment_06.py`: independent integrity and analytical-consistency verification.
- `../../notebooks/06_weather_climate_trends.ipynb`: executed notebook.

## Reproduce and verify

From the repository root:

```bash
python -m pip install -r data/assignment-06/requirements.txt
python data/assignment-06/scripts/run_assignment_06_weather_climate.py --offline
python data/assignment-06/scripts/build_assignment_06_notebook.py
jupyter nbconvert \
  --execute \
  --to notebook \
  --inplace \
  notebooks/06_weather_climate_trends.ipynb \
  --ExecutePreprocessor.timeout=900
python data/assignment-06/verify_assignment_06.py
```

The analysis command regenerates the PNG figures and dashboard assets from the committed authentic source data. SVG figures and analytical tables remain committed for direct review. GitHub Actions performs the same clean-checkout regeneration and verification.
